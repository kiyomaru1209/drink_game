# 飲み会ミニゲーム Webアプリ 要件定義

AI駆動開発向けの軽めの要件定義書。

## 1. 概要

参加者の名前を入力するだけで、飲み会やイベントで使えるミニゲームを遊べるWebアプリを作成する。

ユーザーは参加者名を入力し、用意されたゲームを選んで実行する。各ゲームでは、参加者の中からランダムに1人または複数人を選び、場を盛り上げる。

アプリはスマートフォンで使いやすい画面にする。ログインやデータ保存は不要とし、シンプルにその場で使えるものにする。

## 2. 目的

- 飲み会で手軽に使えるゲームを作る
- 名前を入力するだけで遊べるようにする
- ルール説明が少なくても直感的に使えるようにする
- スマートフォンで操作しやすくする
- 複数のゲームから選んで遊べるようにする

## 3. 基本仕様

### 3.1 参加者入力

- 参加者名を入力できる
- 1行に1人ずつ名前を入力する
- 空行は無視する
- 参加者が2人未満の場合はゲームを開始できない
- 入力した名前は、すべてのゲームで共通して使う

入力例：

```text
佐藤
田中
鈴木
高橋
山本
```

### 3.2 ゲーム選択

参加者名を入力した後、遊びたいゲームを選べるようにする。

初期版では、以下のゲームを用意する。

1. ルーレット
2. あみだくじ
3. 爆弾ゲーム
4. 王様ゲーム
5. 順番決め

## 4. ゲーム仕様

### 4.1 ルーレット

#### 内容

参加者の名前が入ったルーレットを回し、止まった人を選ぶ。

#### 要件

- 参加者名をルーレットに表示する
- ボタンを押すとルーレットが回る
- 最後に選ばれた人を大きく表示する
- 結果表示は盛り上がるように少し派手にする

結果例：

```text
田中さん！
```

### 4.2 あみだくじ

#### 内容

参加者の名前であみだくじを作り、選ばれた人を表示する。

#### 要件

- 参加者数に合わせてあみだくじを作る
- ボタンを押すと結果を表示する
- 可能であれば、選ばれたルートを線で表示する
- スマホでも見やすい表示にする

結果例：

```text
鈴木さん！
```

### 4.3 爆弾ゲーム

#### 内容

参加者の名前を順番に表示し、ランダムなタイミングで爆弾が爆発する。爆発したタイミングで表示されていた人が選ばれる。

#### 要件

- 開始ボタンを押すと名前が次々に切り替わる
- ランダムな秒数で停止する
- 停止した時の名前を結果として表示する
- 爆発っぽい演出を入れる

結果例：

```text
爆発！
山本さん！
```

### 4.4 王様ゲーム

#### 内容

参加者の中から王様を1人選ぶ。

#### 要件

- ボタンを押すと王様を1人決める
- 王様になった人を大きく表示する
- 余裕があれば、王冠などの演出を入れる
- 命令内容はアプリ側では決めなくてよい

結果例：

```text
王様は高橋さん！
```

### 4.5 順番決め

#### 内容

参加者全員の順番をランダムに決める。

#### 要件

- ボタンを押すと参加者をランダムに並び替える
- 1番から順に表示する
- 飲む順番、話す順番、ゲームの順番決めに使える

結果例：

```text
1. 鈴木
2. 佐藤
3. 山本
4. 田中
5. 高橋
```

## 5. 画面構成

画面はシンプルにする。

1. タイトル
2. 参加者名入力欄
3. ゲーム選択ボタン
4. ゲーム表示エリア
5. 結果表示エリア

## 6. デザイン方針

- 飲み会向けに明るく楽しい雰囲気にする
- スマートフォンで使いやすくする
- ボタンは大きめにする
- 結果は大きく見せる
- 操作に迷わない画面にする
- 名前を入れてすぐ遊べる構成にする

## 7. 非対応とするもの

初期版では、以下は作らない。

- ログイン
- 会員登録
- データベース保存
- 複数端末での同期
- 細かい設定画面
- 飲酒量の管理
- 課金機能

## 8. 受け入れ条件

- 参加者名を入力できる
- 参加者が2人以上いればゲームを開始できる
- 参加者が2人未満の場合はエラーを表示する
- ルーレットで1人を選べる
- あみだくじで1人を選べる
- 爆弾ゲームで1人を選べる
- 王様ゲームで1人を選べる
- 順番決めで参加者全員の順番を決められる
- スマートフォンで問題なく操作できる
- 名前を入れるだけで遊べる

## 9. 実装方針

- HTML、CSS、JavaScriptで作成する
- できれば1つの `index.html` で完結させる
- 外部ライブラリは使わなくてよい
- GitHub Pagesなどで公開できる静的Webアプリにする
- データ保存は不要
- ページを閉じたら入力内容は消えてよい

## 10. AIへの実装依頼文

以下の要件で、飲み会向けのミニゲームWebアプリを作成してください。

参加者の名前を1行に1人ずつ入力し、その名前を使って複数のゲームを遊べるようにしてください。ログインや保存機能は不要です。スマートフォンで使いやすい画面にしてください。

作成するゲームは以下です。

- ルーレット
- あみだくじ
- 爆弾ゲーム
- 王様ゲーム
- 順番決め

各ゲームは、参加者名を使ってランダムに結果を出してください。結果は大きく分かりやすく表示してください。

実装は HTML、CSS、JavaScript で行い、可能であれば `index.html` だけで動く形にしてください。

## 11. 注意文

飲酒は無理せず、飲まない人にも配慮して遊んでください。

このアプリは飲酒を強制するものではなく、場を盛り上げるための抽選ツールです。
