# 飲み会ミニゲーム

参加者名を入力して、その場で遊べる飲み会向けミニゲーム Web アプリです。

## 公開URL

https://kiyomaru1209.github.io/drink_game/

## 構成

- `index.html`: 画面構造
- `styles.css`: レイアウト、配色、演出アニメーション
- `app.js`: ゲームロジック、重み付き抽選、ローカル保存、紙吹雪などの演出
- `docs/requirements.md`: 要件定義書

## 機能

- 参加者名と当たりやすさをブラウザの `localStorage` に保存
- 人ごとに当たる確率を 0 から 10 で調整
- ルーレット、あみだくじ、爆弾ゲーム、王様ゲームは重み付き抽選
- 順番決めは重みが高い人ほど前に出やすい並び替え
